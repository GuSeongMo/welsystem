# 5.5.2 프로그램 읽기

#### ■ 프로그램 읽기(파일명 읽기)

{% stepper %}
{% step %}
메인 화면에서 '프로그램 선택'을 누릅니다.

<figure><img src="../.gitbook/assets/2025-04-02 18 32 17.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
읽기 버튼을 누르면 창 탐색기가 나타납니다.

<figure><img src="../.gitbook/assets/2025-04-02 18 32 17 (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
DATA 폴더 안의 프로그램을 선택하여 열기버튼을 누릅니다.

<figure><img src="../.gitbook/assets/2025-04-02 18 32 17 (3).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
설정 완료를 선택해 저장된 프로그램을 읽어올 수 있습니다.

<figure><img src="../.gitbook/assets/2025-04-02 18 32 17 (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
여러 프로그램을 읽을 수도 있습니다.

<figure><img src="../.gitbook/assets/2025-04-02 18 32 17 (5).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
이 경우 위에서부터 차례로 진행합니다.

<figure><img src="../.gitbook/assets/2025-04-02 18 32 17 (6).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
