# 5.3 프로그램 수정

#### ■ 로봇 이동

로봇이동 기능은 교시되어 있는 위치로 로봇을 이동시키는 기능입니다.&#x20;

이 기능은 교시 위치 확인, 중도 실행을 위한 이동 시에 사용합니다.&#x20;

이 기능은 사용할 때는 안전 관련 주의가 필요합니다. 로봇이동 버튼을 누르는 동안 로봇이 이동하며, \
버튼에서 손을 놓는 순간 로봇은 즉시 정지합니다.&#x20;

(실행화면에서의 사용도 가능합니다.)

<figure><img src="../.gitbook/assets/2025-04-03 14 03 51.png" alt=""><figcaption></figcaption></figure>

{% stepper %}
{% step %}
번호를 확인 후 로봇 이동 버튼을 누릅니다.
{% endstep %}

{% step %}
로봇 이동이 완료 되면 해당버튼이 녹색으로 바뀝니다.
{% endstep %}
{% endstepper %}

***

#### ■ 부가축 이동

부가축 이동 기능은 교시되어 있는 위치로 부가축을 이동시키는 기능입니다.&#x20;

이 기능은 교시 위치 확인, 중도 실행을 위한 이동 시 사용합니다.&#x20;

이 기능은 안전 관련 주의가 필요합니다. 부가축 이동 버튼을 누르는 동안 움직이므로 안전 관련 주의가 필요하며 손을 놓는 순간 정지합니다.&#x20;

(부가축이 적용되어  있어야 합니다.)

<figure><img src="../.gitbook/assets/2025-04-03 14 16 41.png" alt=""><figcaption></figcaption></figure>

{% stepper %}
{% step %}
번호를 확인 후 위치 이동 버튼을 누릅니다.
{% endstep %}

{% step %}
부가축이 이동 완료 되면 해당버튼이 녹색으로 바뀝니다.
{% endstep %}
{% endstepper %}

***

#### ■ 위치 수정

선택된 번호의 위치에 현재 로봇의 위치를 덮어쓰고 수정합니다. (실행화면에서의 사용도 가능합니다.)

<figure><img src="../.gitbook/assets/2025-04-03 14 03 51 (4).png" alt=""><figcaption></figcaption></figure>

{% stepper %}
{% step %}
수정할 위치로 로봇을 이동 합니다.
{% endstep %}

{% step %}
번호 확인 후 위치 수정 버튼을 누릅니다.
{% endstep %}

{% step %}
다시 확인 메시지를 확인합니다.
{% endstep %}

{% step %}
위치가 변경되면 버튼이 녹색으로 바뀝니다.
{% endstep %}

{% step %}
교시가 완료되면 '실행화면' 버튼을 눌러 실행화면으로 돌아갑니다.
{% endstep %}
{% endstepper %}

***

#### ■ 교시 시작점 변경

어떤 위치에서 연속으로 위치를 변경할 경우 변경 시작 위치를 선택하여 수정해 나갈 수 있습니다.

<figure><img src="../.gitbook/assets/2025-04-03 14 03 51 (2).png" alt=""><figcaption></figcaption></figure>

{% stepper %}
{% step %}
번호 확인 후 교시 시작점 변경 버튼을 누릅니다.
{% endstep %}

{% step %}
변경 구간을 연속으로 교시합니다.
{% endstep %}

{% step %}
교시가 완료되면 '실행화면' 버튼을 눌러 실행화면으로 돌아갑니다.
{% endstep %}
{% endstepper %}
